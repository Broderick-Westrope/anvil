Create or overwrite a file with given content; auto-creates parent dirs. Cannot append. Overwriting an existing file requires having seen its current content this session — satisfied by a prior view, edit, multiedit, write, or lsp_rename of the file. If the file was never seen or changed on disk since, the call fails once and returns the current content; that failure counts as a read, so re-issuing the same write succeeds. New files are exempt. The response includes a unified diff of the change (truncated when long). For surgical changes use edit or multiedit.
