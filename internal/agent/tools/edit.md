Edit a file by exact find-and-replace; can also create or delete content. No prior read is required: a unique old_string match against the file's current content is the safety mechanism. If old_string differs from the file only in whitespace, the matching lines are still edited and new_string is re-indented to the file's style; the response says when this happened. The response includes a unified diff of the change (truncated when long), so verify the result from it instead of re-reading the file. For renames prefer `lsp_rename` (semantic, cross-file). For large edits use write.
