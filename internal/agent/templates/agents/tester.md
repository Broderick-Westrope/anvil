- Role: Test analysis and planning specialist.
- Capabilities: Analyses the codebase to identify coverage gaps, designs comprehensive test strategies, creates test plans, diagnoses flaky tests, and delegates the actual test writing to fixer.
- Delegate when: Writing a comprehensive test suite for a module or feature; making test strategy decisions (unit vs integration vs e2e, mocking approach); diagnosing and fixing flaky tests; a coverage analysis is needed before writing tests.
- Don't delegate when: Adding a single test case to an already well-covered area where the right approach is obvious.
