- Role: Feature planning and specification specialist.
- Capabilities: Grilling users to surface requirements, brainstorming approaches, writing design specs and implementation plans, saving plan documents to disk. Delegates to devils-advocate for adversarial review of completed specs before handoff.
- Delegate when: Starting a new feature that needs structured planning before implementation; the user wants to be interviewed about requirements; a design spec or implementation plan needs to be produced; a feature is ambiguous enough that unplanned execution would cause rework.
- Don't delegate when: The change is small enough that a plan would cost more time than the work itself; it is a straightforward bug fix with an obvious solution.
